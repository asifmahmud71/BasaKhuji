# BasaKhuji - A Property Rental App

This is a simple property rental application that allows users to view property listings, update their profile details, and log in/out of the application.

## Features

- **View Property Listings**: Users can browse through a list of available properties for rent.
- **Update Profile**: Users can update their profile details such as full name, email, username, and phone number.
- **Login/Logout**: Users can log in to their account to access the app's features, and they can log out when they're done.

## Technologies Used

- **Firebase Authentication**: Used for user authentication (login/logout).
- **Firebase Firestore**: Used to store user profile details and property listings.

## Getting Started

To run the app locally, follow these steps:

1. Clone this repository to your local machine.
2. Open the project in Android Studio.
3. Connect your Android device or start an emulator.
4. Build and run the project.
